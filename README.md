# Chat with PDF SaaS

> Chat with your PDFs — upload documents, get cited, streamed answers. RAG-powered document Q&A in TypeScript.

## Roadmap

- [x] Project scaffold (layout, README, CI)
- [ ] PDF ingestion + chunking pipeline
- [ ] Vector retrieval over per-doc embeddings
- [ ] RAG answer composer with citations + streaming API
- [ ] Multi-doc SaaS API: upload, library, per-doc sessions
- [ ] Eval + tests + Docker, then self-review and public flip

## Quick start

```bash
npm install
npm test
```
